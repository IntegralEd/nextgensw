# Roles & access: who sees what

Every workspace account has one role. The app decides what each person
can open and see from that role, no matter how a Softr page is set up.

| Role | Who |
|---|---|
| **Intern** | Program interns |
| **Partner** (Employer in Airtable) | Mentors at partner organizations |
| **Coordinator** | The program coordinator (Rhonda) |
| **Admin** | Program leads (Ava, Monique) and David (Super Admin) |

"Staff" below means Coordinators and Admins.

## Pages

| Page | Intern | Partner | Coordinator | Admin |
|---|---|---|---|---|
| Home, Inbox, Events, User guide | ✓ | ✓ | ✓ | ✓ |
| Request a task, Tasks you requested | ✓ | ✓ | ✓ | ✓ |
| Record timesheets, Stopwatch, My hours, My tasks | ✓ | | ✓ | ✓ |
| Review timesheets, Pay periods, All tasks, Cohorts, Reports | | | ✓ | ✓ |
| Testing guide, View as | | | | ✓ |

The full list of pages is in the **Site map** guide.

## Timesheets

- **Interns** see and edit only their own hours.
- **Coordinators** see everyone's submitted hours and can **Mark
  reviewed** or comment. That's their own review track and doesn't
  change payroll.
- **Admins** also **approve hours for payroll** and run the payroll
  cycle (finalize, export, mark paid).
- **Partners never see timesheets.**

## Tasks

- **The assignee** sees the task and updates its status.
- **The requester** sees tasks they asked for. Partners also see every
  task their organization requested.
- **Staff** see every task.
- **Reviewing** (accept or request updates): the requester, the
  requesting partner organization, or staff. Never the assignee.
- **Edit and delete**: staff, the requester, or the requesting partner
  organization.

## Events

- **Everyone sees every event** on the Events page.
- **Staff and partners** can create events. A partner's event is hosted
  by their organization and starts as Optional.
- **Edit, delete and attendance**: staff, or the hosting partner
  organization.
- **Required** events count on the interns' weekly report.

## Messages

Who sees a conversation depends on where it started:

- **Direct and group messages**: the people in them.
- **Task discussions**: the assignee, the requester, the requesting
  partner organization, and staff.
- **Timesheet comments**: the intern and staff. Partners don't see them.
- **Event discussions**: everyone in the workspace.
- **Cohort discussions**: members of that cohort.
- **Staff Only**: staff.

**Staff can read every conversation**, including direct messages, so
the program can keep everyone safe. The message composer says so.

## Cohorts

- **Members** see the cohort's discussions. Only **intern** members
  get tasks sent to the whole cohort and appear on the weekly report.
- **The coordinator** of a cohort is listed on the Cohorts page. When
  adding people, only pick a cohort under "coordinating" for the
  cohort's coordinator.

## What's new card

Each role's card only lists things that role can already see. The
**What's new** guide lists the items per role.

## Test accounts and View as (admins)

- **Test accounts** live in a sandbox. Real interns and partners never
  see what they do, and reports and payroll leave it out. See the
  **Testing guide**.
- **View as** lets an admin see the workspace exactly as an intern,
  partner or coordinator does, read-only and logged.
